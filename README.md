# LucX Auto Detailing — Site

Site estático servido por um pequeno servidor Node/Express.

Para rodar localmente:

```
npm install
npm start
```

Deploy no Railway:
- Faça push do repositório para o GitHub.
- No Railway, crie um novo projeto e conecte o repositório.
- Configure build: `npm install` e start: `npm start`. Railway usa `PORT` automaticamente.
